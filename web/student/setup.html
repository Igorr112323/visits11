Отметка посещаемости

Приложение ставится на экран Домой iPhone за 5 шагов и дальше работает офлайн.
App Store и Apple ID не нужны.

Адрес ПК

Наведите камеру iPhone на код — откроется эта страница. Или введите адрес вручную.

—

1

Скачайте сертификат ПК

Нажмите кнопку ниже в Safari. На вопрос «Разрешить скачивание профиля конфигурации?» ответьте «Разрешить», затем «Закрыть». Откройте Настройки — сверху будет «Профиль загружен» → «Установить» (введите код-пароль iPhone) → ещё раз «Установить».

Скачать сертификат
2

Включите доверие сертификату

Настройки → Основные → Об этом устройстве → Доверие сертификатов — включите переключатель у сертификата visits11.local и подтвердите. Без этого iPhone не разрешит приложению работать офлайн (Service Worker включается только при доверенном сертификате).

3

Откройте приложение по HTTPS

Нажмите кнопку — адрес начнётся с https://. Если Safari пишет «Это подключение не защищено» — нажмите «Дополнительно» → «Перейти на сайт»: страница откроется, но офлайн-режим заработает только после шага 2.

Не входите в Safari. Приложение на экране Домой хранит данные отдельно от Safari — логин и пароль вводите уже в нём (шаг 5).

Открыть по HTTPS
4

Поделиться → «На экран Домой»

Нажмите Поделиться (квадрат со стрелкой ↑) в нижней панели Safari, пролистайте список до пункта «На экран „Домой“» и нажмите «Добавить».

5

Один раз откройте иконку при включённом ПК

Запустите «КубГАУ» с экрана Домой, находясь в Wi-Fi с ПК, и войдите по логину и паролю. Приложение запомнит себя за несколько секунд.

Дальше оно открывается без интернета и без ПК — сколько угодно, хоть через год. Чтобы отметиться, ПК преподавателя по-прежнему должен быть включён и в той же сети.

Открыть приложение

Что важно знать

Адрес ПК зашит в приложение. Оно работает по тому адресу, с которого установлено. Если IP ПК поменяется, придётся выпустить сертификат заново и поставить приложение ещё раз — закрепите за ПК постоянный IP в роутере.

Wi-Fi. ПК и iPhone должны быть в одной сети, а брандмауэр Windows должен пропускать входящие подключения на порт 8090.

| Подпись iPhone-приложения своим Apple ID (Sideloadly) | 0 ₽ |

Дополнительных платежей нет: ничего не хостится в интернете, сервер работает на
ноутбуке преподавателя, Wi-Fi — обычный роутер или мобильная точка доступа ноутбука.

### Ограничения бесплатного Apple ID (это не наш код, это правила Apple)

* подпись живёт **7 дней**, потом приложение нужно подписать заново;
* одновременно на телефоне может стоять **не более 3** приложений, подписанных
  бесплатным аккаунтом, у аккаунта — **3 устройства** и **10 новых App ID в неделю**;
* раздать сборку «по ссылке» нельзя: каждый студент подписывает **своим** Apple ID
  на своём компьютере (10 минут, кабель + Sideloadly).

Платный аккаунт ($99/год) снимает 7-дневный срок, убирает лимит в 3 приложения и
включает NFC — но для работы системы он не требуется.

## 1. Сервер на ноутбуке

### Windows

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/)
   (галочка **Add python.exe to PATH**).
2. Скачайте/скопируйте папку `server/` на ноутбук. В ней откройте PowerShell:

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

3. Windows спросит про доступ в сеть — **разрешите для частных сетей**.
4. В консоли появятся адреса, например `http://192.168.1.10:8000` — это адрес,
   который вводят телефоны. Проверка: откройте его в браузере телефона.

### macOS / Linux

```bash
cd server
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

### Полезно

* Другой порт: `uvicorn main:app --host 0.0.0.0 --port 8080`
  (тогда в приложениях указывайте адрес с портом, `192.168.1.10:8080`).
* API-ключ: `API_KEY=mysecret uvicorn main:app --host 0.0.0.0 --port 8000`
  — тогда приложения должны слать заголовок `X-Api-Key` (в мобильных клиентах
  он пока не настроен, так что для тестов лучше без ключа).
* Проверка «глазами преподавателя»: `GET /api/attendance/<session_id>` или
  выгрузка в Excel: `GET /api/attendance/<session_id>/export.csv`.
* Если ноутбук не в общей сети с телефоном: включите **мобильную точку доступа**
  на ноутбуке (Windows: «Мобильный хот-спот») и подключите телефоны к ней —
  адрес ноутбука в такой сети обычно `192.168.137.1`.

## 2. Android-приложение преподавателя

### Вариант А. Готовый APK из CI (быстрее всего)

1. Откройте [Releases → nfc-v1.0.0](https://github.com/Igorr112323/visits11/releases)
   и скачайте `NFC-Attendance-Teacher.apk`.
2. Установка по кабелю:

```bash
# на телефоне включите «Для разработчиков» → «Отладка по USB»
adb devices                     # телефон должен появиться в списке
adb install -r NFC-Attendance-Teacher.apk
```

Без кабеля: перенесите APK на телефон (файлом, по Bluetooth, через облако) и
откройте — Android попросит разрешить установку из неизвестного источника.

APK из CI подписан **тестовым ключом**, который создаётся на раннере. Это значит:
для обновления поверх установленной версии может понадобиться удалить приложение.
Если нужна стабильная подпись — добавьте в секреты репозитория свой keystore
(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD`), workflow подхватит их автоматически.

### Вариант Б. Сборка в Android Studio

1. Установите [Android Studio](https://developer.android.com/studio) (JDK 17 идёт в комплекте).
2. `File → Open` → папка `nfc-attendance/android`.
3. Дождитесь Gradle Sync, подключите телефон по USB, нажмите ▶ **Run**.
   Либо соберите APK: `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

### Что нужно на телефоне преподавателя

* Android 8.0+ и включённый **Bluetooth** — это основной канал отметки.
  Приложение при первом запуске попросит разрешения Bluetooth (на Android 12+
  их четыре: «Рядом с устройствами» / `BLUETOOTH_ADVERTISE`, `CONNECT`, `SCAN`).
* Разрешение **на уведомления** — BLE-метка работает в foreground-сервисе,
  в шторке висит уведомление «Метка КубГАУ активна». Без него метка не проживёт
  в фоне, и телефон перестанет отвечать, лёжа на столе.
* **NFC** — необязателен, включается только для запасного NFC-пути
  (Настройки → Подключения → NFC). iPhone-студент читает его лишь с платным
  аккаунтом Apple.
* Питание: на время пары отключите для приложения агрессивную экономию батареи
  (`Настройки → Приложения → КубГАУ Преподаватель → Батарея → Без ограничений`),
  иначе система может остановить foreground-сервис.

## 3. iPhone-приложение студента

### Что важно знать заранее

| Возможность | Бесплатный Apple ID (Personal Team) | Платный аккаунт ($99/год) |
|---|---|---|
| Установка приложения по кабелю | ✅ да | ✅ да |
| Срок жизни подписи | ⏳ 7 дней (потом подписать заново) | 1 год |
| **Bluetooth-касание (BLE)** — основной канал | ✅ **да** | ✅ да |
| **NFC-чтение (CoreNFC)** | ❌ **нет** — capability «NFC Tag Reading» бесплатной подписью не выдаётся | ✅ да |

Поэтому бесплатный сценарий полностью рабочий: отметка идёт по **Bluetooth** —
студент так же прикладывает телефон, просто«касание»идёт не через NFC, а через BLE.
NFC включится сам, если у вас есть платный аккаунт разработчика.

### 3.1. Установка и подпись через Sideloadly — пошагово (Windows или macOS)

> Есть короткая версия этой инструкции одной страницей:
> **[КАК-ПОСТАВИТЬ-НА-IPHONE.md](КАК-ПОСТАВИТЬ-НА-IPHONE.md)** — с теми же ссылками
> и шагами, без подробностей.

Это основной путь: качаете две программы, файл приложения — и через 10 минут
приложение стоит на телефоне.

#### Что скачать

| Что | Ссылка | Зачем |
|---|---|---|
| **Sideloadly** (Windows, 64-bit) | **[sideloadly.io/SideloadlySetup64.exe](https://sideloadly.io/SideloadlySetup64.exe)** | сама подпись и установка по кабелю |
| Sideloadly для macOS | [sideloadly.io/SideloadlySetup.dmg](https://sideloadly.io/SideloadlySetup.dmg) | то же на Mac |
| **iTunes** (веб-версия, 64-bit) | **[apple.com/itunes/download/win64](https://www.apple.com/itunes/download/win64)** | драйверы для iPhone. Только Windows |
| **iCloud** (веб-версия) | [iCloudSetup.exe](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe) | Sideloadly требует его на Windows |
| **Наше приложение** (IPA, 231 КБ) | [NFC-Attendance-Student-unsigned.ipa](https://github.com/Igorr112323/visits11/releases/download/nfc-v1.0.0/NFC-Attendance-Student-unsigned.ipa) | то, что ставим на iPhone |

На macOS iTunes и iCloud не нужны — достаточно Sideloadly.

**Если ссылка на Sideloadly не открывается** (сайт заблокирован в вашей сети или
к ссылке приклеился текст) — скачайте открытую программу **Impactor**, она лежит
на GitHub и делает то же самое:

```
Windows x64  https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-windows-x86_64-setup.exe
Windows x86  https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-windows-x86-setup.exe
macOS        https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-macos-universal.dmg
Все сборки   https://github.com/claration/impactor/releases
```

Порядок тот же (iTunes/iCloud для драйверов, Apple ID бесплатный): подключить
iPhone → перетащить `.ipa` в окно → ввести Apple ID → нажать установку.

> Важно про Windows: если iTunes или iCloud уже стояли **из Microsoft Store** —
> сначала удалите их. Sideloadly работает только с обычными («web») версиями
> с сайта Apple, иначе будет ошибка `NP_E_CONN_FAILED`.

#### Что нужно до начала

* iPhone с **iOS 16 или новее** (iPhone 8 / SE 2 и новее); в настройках должно
  быть свободное место.
* **Apple ID** — ваш обычный, можно бесплатный. Отдельный заводить не обязательно;
  Apple ID нужен только для подписи, входить в него на самом iPhone не надо.
* Кабель, которым iPhone точно синхронизируется с компьютером (не «только зарядка»).
* 15 минут и компьютер с USB-портом.

#### Шаги

1. **Установите iTunes** (файл из таблицы) → **iCloud** → **Sideloadly**.
   Перезагрузите компьютер.
2. **Подключите iPhone кабелем**, разблокируйте. На телефоне спросит
   «Доверять этому компьютеру?» → **Доверять** → введите пароль экрана.
3. **Один раз синхронизируйте телефон:** откройте iTunes → устройство →
   **Синхронизировать**. Там же: **Учётная запись → Авторизовать этот компьютер**
   → войдите своим Apple ID. Этот шаг убирает половину ошибок входа
   (например `36607`, «последнее соединение не удалось»).
4. **Скачайте IPA** по ссылке из таблицы (положите, например, в «Загрузки»).
5. **Запустите Sideloadly.** iPhone должен появиться в списке устройств слева
   вверху (если нет — см. «Частые проблемы»).
6. **Подпишите и поставьте:**
   * в поле **Apple ID** — ваш Apple ID (можно бесплатный);
   * **перетащите IPA** в окно (или нажмите `IPA` и выберите файл);
   * убедитесь, что включена галочка **Automatic App Refresh** (она включена
     по умолчанию — это автопродление подписи, см. шаг 9);
   * нажмите **Start**;
   * введите **пароль Apple ID**. Если включена двухфакторная аутентификация —
     Sideloadly попросит **6-значный код**, его покажет iPhone (или возьмите код
     в Настройках телефона). Пароль для приложений создавать не нужно: с
     бесплатным Apple ID он не работает.
7. Дождитесь надписи **Done!** (обычно 10–60 секунд). Sideloadly сам создаст
   сертификат, подпишет приложение и установит его.
8. **Доверьте профилю на iPhone:** Настройки → Основные → VPN и управление
   устройством → под «Профиль разработчика» нажмите на ваш Apple ID → **Доверять**.
9. **Включите режим разработчика** (iOS 16+): Настройки → Конфиденциальность
   и безопасность → **Режим разработчика** → включить → телефон перезагрузится,
   после перезагрузки подтвердите. Пункт появляется после первой попытки
   установки/запуска — если его no, откройте приложение и загляните снова.
10. **Запустите приложение «КубГАУ Студент»** и разрешите всё, что спросит:
    **Локальная сеть**, **Bluetooth**, уведомления. Затем во вкладке
    **«Настройки»** укажите адрес преподавательского ноутбука (например
    `192.168.1.10`) и свой логин с вкладки «Студенты» → «Проверить связь».
11. Готово: вкладка **«Отметиться»** → приложите iPhone к телефону преподавателя.

#### Чтобы не повторять каждые 7 дней

Бесплатная подпись живёт 7 дней, но Sideloadly умеет продлевать её сам:

1. В Sideloadly оставьте включённой галочку **Automatic App Refresh** (шаг 6).
   Приложение «записывается» на автопродление.
2. На Windows включите Wi-Fi-синхронизацию: iTunes → устройство → **Обзор →
   Параметры → Синхронизировать с этим iPhone по Wi-Fi → Применить** (на Mac —
   в Finder: «Показывать этот iPhone по Wi-Fi»).
3. Держите включённым **Sideloadly Daemon** — он живёт в системном трее
   (на Mac — в строке меню) и запускается вместе с компьютером.
4. Пока компьютер и телефон в одной Wi-Fi сети, демон сам переподпишет
   приложение до истечения 7 дней. Если компьютера рядом нет — раз в неделю
   подключите телефон кабелем и повторите шаги 6–7: данные сохранятся.

### 3.1.1. Частые ошибки при установке на iPhone

| Ошибка / симптом | Что делать |
|---|---|
| Sideloadly не видит iPhone (`<no devices detected>`) | переустановите **веб-версии** iTunes и iCloud, перезагрузите ПК, откройте iTunes и синхронизируйте; на телефоне нажмите «Доверять»; попробуйте другой кабель/порт |
| `Login failed (-36607)`, «не удалось войти в Apple ID» | в iTunes: **Учётная запись → Авторизовать этот компьютер**, войдите тем же Apple ID, затем снова Start |
| `Your maximum App ID limit has been reached (10 App IDs every 7 days)` | ограничение Apple на бесплатный аккаунт: подождите несколько дней или используйте другой Apple ID |
| `This device has reached the maximum number of installed apps using a free developer profile` | на телефоне уже 3 приложения, подписанных бесплатным аккаунтом: удалите лишние |
| `Untrusted Developer` при запуске | Настройки → Основные → VPN и управление устройством → Apple ID → Доверять |
| `Invalid argument /path/app.ipa` | антивирус удалил или запер файл: скачайте IPA заново, добавьте в исключения |
| Приложение не появилось на экране | перезагрузите iPhone |
| `NP_E_CONN_FAILED`, `AFC_E_MUX_ERROR` | установлена версия iTunes из Microsoft Store: удалите её и поставьте веб-версию |
| `No space left on device` | мало места на **компьютере** (не на телефоне) — освободите диск |
| `The identity used to sign is no longer valid` / `provisioning profile not found` | неверные дата/время на компьютере или телефоне — поставьте автоматическое время |
| Приложение перестало открываться через 7 дней | истёк срок бесплатной подписи: повторите шаги 6–7 (данные сохранятся) |

### 3.2. Установка через Xcode (свой Apple ID, тоже бесплатно)

Понадобится macOS. Бесплатный аккаунт даёт то же ограничение по NFC, что и выше.

```bash
brew install xcodegen
cd nfc-attendance/ios
xcodegen generate          # создаст Visits11Student.xcodeproj
open Visits11Student.xcodeproj
```

В Xcode:

1. **Xcode → Settings → Accounts → +** → Apple ID (бесплатный).
2. Выберите таргет `Visits11Student` → вкладка **Signing & Capabilities**:
   * **Team**: Personal Team;
   * **Bundle Identifier**: сделайте уникальным, например
     `ru.ivanov.kubgau.student` (бесплатные App ID должны быть свободны);
   * если Xcode ругается на capability **NFC Tag Reading** — удалите строку
     `com.apple.developer.nfc.readersession.formats` из
     `Sources/Visits11Student.entitlements`: приложение продолжит работать
     (отметка по Bluetooth), а NFC просто не включится.
3. Подключите iPhone кабелем, выберите его как устройство, нажмите ▶ **Run**.
4. На iPhone разрешите профиль разработчика (шаг 6–7 из прошлого раздела).

С платным аккаунтом: оставьте entitlement на месте, в **Signing & Capabilities**
добавьте + **Near Field Communication Tag Reading** — и кнопка «Отметить по NFC»
внизу вкладки «Отметиться» заработает (она откроет системное окно чтения метки).

### 3.3. Настройка приложения студента

* Вкладка **«Настройки»**:
  * «Сервер преподавателя» — IP ноутбука (например `192.168.1.10`; порт 8000
    подставится сам). Кнопка «Проверить связь» → должно быть «есть».
  * «Логин» — логин со вкладки «Студенты» на ПК (например `ARHIPOV_II`),
    «ФИО» — как в журнале.
  * Здесь же виден `device_id` — он создаётся один раз и в Keychain.
* Первый запуск попросит разрешения **«Локальная сеть»** и **«Bluetooth»** —
  разрешите оба: по Bluetooth идёт касание, по сети — отправка отметки.
* Отметка: вкладка **«Отметиться»** и приложить iPhone к телефону преподавателя.
  Кнопку нажимать не нужно — приложение найдёт метку само.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Сервер не отвечает» в Android-приложении | ноутбук и телефон в разных сетях; или брандмауэр блокирует порт 8000; или uvicorn запущен с `--host 127.0.0.1` вместо `0.0.0.0` |
| iPhone не видит сервер, «нет связи» | не разрешено «Локальная сеть» (Настройки iPhone → приложение → переключатель); либо адрес без порта и он не 8000 |
| Студент: «Поднесите телефон ближе» | сигнал слабее порога дистанции: поднесите телефон вплотную или попросите преподавателя переключить дистанцию на «Рядом»/«Свободно» |
| Студент: «Терминал не найден» | у преподавателя не начата эмуляция, выключен Bluetooth на одном из телефонов, или телефон студента слишком далеко |
| Установка IPA падает с ошибкой подписи | bundle id занят — поменяйте его; или Apple ID требует app-specific password; или 10 App ID за неделю израсходованы (подождите 4–7 дней) |
| Приложение на iPhone перестало открываться через 7 дней | истекла бесплатная подпись — подпишите заново через Sideloadly |
| NFC-кнопка пишет «не удалось» | нет capability NFC Tag Reading (нужен платный аккаунт) — отметка всё равно пройдёт по Bluetooth |
| Android: «NFC выключен» | включите NFC; HCE не работает при полностью разряженном/выключенном NFC |
| Android: «BLE-метка выключена» | не выданы разрешения Bluetooth или выключен Bluetooth; откройте приложение и разрешите |
| Студент отмечен «без касания» | он отметился, когда телефон преподавателя не видел касания (например, приложение было закрыто) |

## 1. Сервер на ноутбуке

### Windows

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/)
   (галочка **Add python.exe to PATH**).
2. Скачайте/скопируйте папку `server/` на ноутбук. В ней откройте PowerShell:

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

3. Windows спросит про доступ в сеть — **разрешите для частных сетей**.
4. В консоли появятся адреса, например `http://192.168.1.10:8000` — это адрес,
   который вводят телефоны. Проверка: откройте его в браузере телефона.

### macOS / Linux

```bash
cd server
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

### Полезно

* Другой порт: `uvicorn main:app --host 0.0.0.0 --port 8080`
  (тогда в приложениях указывайте адрес с портом, `192.168.1.10:8080`).
* API-ключ: `API_KEY=mysecret uvicorn main:app --host 0.0.0.0 --port 8000`
  — тогда приложения должны слать заголовок `X-Api-Key` (в мобильных клиентах
  он пока не настроен, так что для тестов лучше без ключа).
* Проверка «глазами преподавателя»: `GET /api/attendance/<session_id>` или
  выгрузка в Excel: `GET /api/attendance/<session_id>/export.csv`.
* Если ноутбук не в общей сети с телефоном: включите **мобильную точку доступа**
  на ноутбуке (Windows: «Мобильный хот-спот») и подключите телефоны к ней —
  адрес ноутбука в такой сети обычно `192.168.137.1`.

## 2. Android-приложение преподавателя

### Вариант А. Готовый APK из CI (быстрее всего)

1. Откройте [Releases → nfc-v1.0.0](https://github.com/Igorr112323/visits11/releases)
   и скачайте `NFC-Attendance-Teacher.apk`.
2. Установка по кабелю:

```bash
# на телефоне включите «Для разработчиков» → «Отладка по USB»
adb devices                     # телефон должен появиться в списке
adb install -r NFC-Attendance-Teacher.apk
```

Без кабеля: перенесите APK на телефон (файлом, по Bluetooth, через облако) и
откройте — Android попросит разрешить установку из неизвестного источника.

APK из CI подписан **тестовым ключом**, который создаётся на раннере. Это значит:
для обновления поверх установленной версии может понадобиться удалить приложение.
Если нужна стабильная подпись — добавьте в секреты репозитория свой keystore
(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD`), workflow подхватит их автоматически.

### Вариант Б. Сборка в Android Studio

1. Установите [Android Studio](https://developer.android.com/studio) (JDK 17 идёт в комплекте).
2. `File → Open` → папка `nfc-attendance/android`.
3. Дождитесь Gradle Sync, подключите телефон по USB, нажмите ▶ **Run**.
   Либо соберите APK: `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

### Что нужно на телефоне преподавателя

* Android 8.0+ с поддержкой **HCE** (есть почти у всех телефонов с NFC).
* Включённый **NFC** (Настройки → Подключения → NFC).
* Приложение должно быть хотя бы раз открыто: тогда HCE-сервис активен, и метка
  отвечает даже при погашенном экране (`requireDeviceUnlock="false"`).
* Питание: телефон должен не «уснуть» окончательно — на время пары лучше
  отключить агрессивную экономию батареи для приложения.

## 3. iPhone-приложение студента

### Что важно знать заранее

| Возможность | Бесплатный Apple ID (Personal Team) | Платный аккаунт ($99/год) |
|---|---|---|
| Установка приложения по кабелю | ✅ да | ✅ да |
| Срок жизни подписи | ⏳ 7 дней (потом подписать заново) | 1 год |
| **Bluetooth-касание (BLE)** — основной канал | ✅ **да** | ✅ да |
| **NFC-чтение (CoreNFC)** | ❌ **нет** — capability «NFC Tag Reading» бесплатной подписью не выдаётся | ✅ да |

Поэтому бесплатный сценарий полностью рабочий: отметка идёт по **Bluetooth** —
студент так же прикладывает телефон, просто「касание」идёт не через NFC, а через BLE.
NFC включится сам, если у вас есть платный аккаунт разработчика.

### 3.1. Установка через Sideloadly (бесплатно, 7 дней) — Windows или macOS

1. Скачайте и установите [Sideloadly](https://sideloadly.io/) и
   [iTunes](https://www.apple.com/itunes/) (нужен для драйверов Apple Mobile Device;
   на macOS — достаточно Xcode, но обычно всё работает и без него).
2. Скачайте из релиза неподписанный файл `NFC-Attendance-Student-unsigned.ipa`.
3. Подключите iPhone кабелем, разблокируйте его, нажмите «Доверять этому
   компьютеру», если спросит. Bluetooth на телефоне должен быть включён —
   по нему работает отметка.
4. Откройте Sideloadly:
   * **Apple ID**: ваш обычный Apple ID (можно бесплатный);
   * перетащите `.ipa` в окно;
   * нажмите **Start**;
   * когда появится запрос — введите пароль Apple ID
     (лучше создать [app-specific password](https://appleid.apple.com/) —
     тогда обычный пароль светить не нужно).
5. Sideloadly сам подпишет приложение вашим сертификатом (Personal Team) и
   установит по кабелю. Уникальный Bundle ID менять не нужно.
6. На iPhone: **Настройки → Основные → VPN и управление устройством →
   Профиль разработчика → Доверять**.
7. Запустите приложение «КубГАУ Студент».
   Если iOS 16+ пишет про «Режим разработчика»: **Настройки → Конфиденциальность
   и безопасность → Режим разработчика → включить** → телефон перезагрузится.

Через 7 дней приложение перестанет открываться («не удалось проверить
разработчика») — просто повторите шаги 3–5 (данные Core Data сохранятся).

### 3.2. Установка через Xcode (свой Apple ID, тоже бесплатно)

Понадобится macOS. Бесплатный аккаунт даёт то же ограничение по NFC, что и выше.

```bash
brew install xcodegen
cd nfc-attendance/ios
xcodegen generate          # создаст Visits11Student.xcodeproj
open Visits11Student.xcodeproj
```

В Xcode:

1. **Xcode → Settings → Accounts → +** → Apple ID (бесплатный).
2. Выберите таргет `Visits11Student` → вкладка **Signing & Capabilities**:
   * **Team**: Personal Team;
   * **Bundle Identifier**: сделайте уникальным, например
     `ru.ivanov.kubgau.student` (бесплатные App ID должны быть свободны);
   * если Xcode ругается на capability **NFC Tag Reading** — удалите строку
     `com.apple.developer.nfc.readersession.formats` из
     `Sources/Visits11Student.entitlements`: приложение продолжит работать
     (отметка по Bluetooth), а NFC просто не включится.
3. Подключите iPhone кабелем, выберите его как устройство, нажмите ▶ **Run**.
4. На iPhone разрешите профиль разработчика (шаг 6–7 из прошлого раздела).

С платным аккаунтом: оставьте entitlement на месте, в **Signing & Capabilities**
добавьте + **Near Field Communication Tag Reading** — и кнопка «Отметиться»
(NFC) заработает.

### 3.3. Настройка приложения студента

* Вкладка **«Настройки»**:
  * «Сервер преподавателя» — IP ноутбука (например `192.168.1.10`; порт 8000
    подставится сам). Кнопка «Проверить связь» → должно быть «есть».
  * «Логин» — логин со вкладки «Студенты» на ПК (например `ARHIPOV_II`),
    «ФИО» — как в журнале.
  * Здесь же виден `device_id` — он создаётся один раз и в Keychain.
* Первый запуск попросит разрешения **«Локальная сеть»** и **«Bluetooth»** —
  разрешите оба: по Bluetooth идёт касание, по сети — отправка отметки.
* Отметка: вкладка **«Отметиться»** и приложить iPhone к телефону преподавателя.
  Кнопку нажимать не нужно — приложение найдёт метку само.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Сервер не отвечает» в Android-приложении | ноутбук и телефон в разных сетях; или брандмауэр блокирует порт 8000; или uvicorn запущен с `--host 127.0.0.1` вместо `0.0.0.0` |
| iPhone не видит сервер, «нет связи» | не разрешено «Локальная сеть» (Настройки iPhone → приложение → переключатель); либо адрес без порта и он не 8000 |
| Студент: «Поднесите телефон ближе» | сигнал слабее порога дистанции: поднесите телефон вплотную или попросите преподавателя переключить дистанцию на «Рядом»/«Свободно» |
| Студент: «Терминал не найден» | у преподавателя не начата эмуляция, выключен Bluetooth на одном из телефонов, или телефон студента слишком далеко |
| Установка IPA падает с ошибкой подписи | bundle id занят — поменяйте его; или Apple ID требует app-specific password; или 10 App ID за неделю израсходованы (подождите 4–7 дней) |
| Приложение на iPhone перестало открываться через 7 дней | истекла бесплатная подпись — подпишите заново через Sideloadly |
| NFC-кнопка пишет «не удалось» | нет capability NFC Tag Reading (нужен платный аккаунт) — отметка всё равно пройдёт по Bluetooth |
| Android: «NFC выключен» | включите NFC; HCE не работает при полностью разряженном/выключенном NFC |
| Android: «BLE-метка выключена» | не выданы разрешения Bluetooth или выключен Bluetooth; откройте приложение и разрешите |
| Студент отмечен «без касания» | он отметился, когда телефон преподавателя не видел касания (например, приложение было закрыто) |
| Студенту пишет «телефон привязан к другому студенту» | этот iPhone уже отметился за другого: уберите привязку в базе (`UPDATE students SET device_id = NULL WHERE id = '…'`) или отметьте вручную |

# КАК ПОСТАВИТЬ ПРИЛОЖЕНИЕ НА IPHONE

Короткая памятка. Подробная версия — [INSTALL_AND_SIGNING.md](INSTALL_AND_SIGNING.md#31-установка-и-подпись-через-sideloadly--пошагово-windows-или-macos).

Нужен **компьютер** (Windows или Mac) и кабель. Всё бесплатно.

---

## ШАГ 0. Скачать программы и наше приложение

### Если компьютер на Windows 10 или 11 (64-бит)

Ссылки (копируйте **целиком, без лишних слов** — если ссылка «не открывается»,
скорее всего к ней приклеился текст):

```
1) Sideloadly          https://sideloadly.io/SideloadlySetup64.exe
2) iTunes (веб-версия) https://www.apple.com/itunes/download/win64
3) iCloud (веб-версия) https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe
4) Наше приложение     https://github.com/Igorr112323/visits11/releases/download/nfc-v1.0.0/NFC-Attendance-Student-unsigned.ipa
```

| № | Что это | Размер |
|---|---|---|
| 1 | **Sideloadly** — подписывает и ставит приложение | ~126 МБ |
| 2 | **iTunes** (обычная «веб»-версия) — драйверы для iPhone | ~230 МБ |
| 3 | **iCloud** (обычная «веб»-версия) — требует Sideloadly | ~180 МБ |
| 4 | **Наше приложение** (IPA) | 0,2 МБ |

### Если компьютер на macOS

```
1) Sideloadly  https://sideloadly.io/SideloadlySetup.dmg
2) Приложение  https://github.com/Igorr112323/visits11/releases/download/nfc-v1.0.0/NFC-Attendance-Student-unsigned.ipa
```

iTunes и iCloud на Mac не нужны.

> **ВАЖНО (особенно на Windows 11):** нельзя ставить iTunes/iCloud из
> Microsoft Store — Sideloadly не видит телефон с ними. Windows 11 сам
> предлагает их в Store, поэтому:
>
> 1. Откройте **Параметры → Приложения → Установленные приложения**.
> 2. Найдите и удалите: **iTunes**, **iCloud**, **Apple Devices**, **Apple Music**,
>    **Apple TV** — всё от Apple, что установлено из Store.
> 3. Поставьте обычные версии по ссылкам выше (это «классические» установщики
>    Apple, они ставят драйверы **Apple Mobile Device Support** — именно их
>    использует Sideloadly).
>
> На Windows 11 скачивайте файлы **64-бит** — система всегда 64-битная
> (даже если ноутбук на ARM-процессоре, установщик x64 запустится в режиме
> совместимости).

### Windows 11: что ещё может помешать

| Что происходит | Что делать |
|---|---|
| При запуске установщика: «Windows защитила ваш компьютер» (SmartScreen) | нажмите **Подробнее** → **Выполнить в любом случае** |
| Защитник Windows удалил файл `sideloadly.dll` из папки программы | Защитник Windows → **Защита от вирусов и угроз** → «Исключения» → добавить папку `C:\Program Files\Sideloadly` |
| Установщик отказывается запускаться | Параметры → Система → **О системе**: должна быть «64-разрядная операционная система»; если включён режим Windows S — его нужно отключить (Параметры → Конфиденциальность и защита → Безопасность Windows) |
| Sideloadly не видит iPhone, хотя программы установлены | в Диспетчере устройств должен быть **Apple Mobile Device USB Driver** без восклицательного знака; если со знаком — переустановите iTunes с сайта Apple и перезагрузитесь |
| iPhone не появляется в iTunes | другой порт/кабель (USB-хабы и док-станции иногда мешают), затем на телефоне нажмите «Доверять» |

### Ссылка на Sideloadly не открывается? — ставьте Impactor вместо него

**Impactor** — открытая программа (лицензия MIT), которая делает ровно то же
самое: подписывает `.ipa` вашим Apple ID и ставит его на iPhone по кабелю.
Качается **с GitHub** — по той же дороге, по которой вы уже скачали наше
приложение, поэтому доступна всегда.

```
Windows (64-бит)  https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-windows-x86_64-setup.exe
Windows (32-бит)  https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-windows-x86-setup.exe
macOS             https://github.com/claration/impactor/releases/download/v2.6.5/Impactor-macos-universal.dmg
Страница со всеми файлами  https://github.com/claration/impactor/releases
```

Не уверены, какая у вас Windows — 32 или 64 бита? Нажмите **Win + R**, введите
`winver` и посмотрите; подойдёт и 64-битная версия почти всегда.

**Как ставить через Impactor (заменяет ШАГ 4):**

1. Убедитесь, что **iTunes** установлена (вы её уже скачали) — Impactor берёт из
   неё драйверы для iPhone. **iCloud для Impactor не нужен** — он нужен только
   Sideloadly.
2. Установите Impactor и запустите.
3. Подключите iPhone кабелем, разблокируйте, нажмите **«Доверять»**.
4. **Перетащите** скачанный файл `NFC-Attendance-Student-unsigned.ipa` в окно
   программы (или выберите его через кнопку выбора файла).
5. Введите ваш **Apple ID** и пароль. Если включена двухфакторная
   аутентификация — введите 6-значный код с телефона.
6. Нажмите кнопку установки и дождитесь сообщения об успехе (обычно 10–60 секунд).
7. Дальше — обычные **ШАГ 5** (доверить профиль, включить режим разработчика)
   и **ШАГ 6** (настроить сервер и отметиться).

Сроки и лимиты те же, что у Sideloadly: бесплатная подпись на 7 дней, не больше
3 приложений от бесплатного Apple ID. Автопродления, как в Sideloadly, тут нет —
раз в неделю просто повторите пункты 4–6.

### Если и сайт Sideloadly, и GitHub не открываются

Проблема тогда не в ссылке, а в доступе к сайтам из вашей сети. Что помогает:

1. Смените DNS на `8.8.8.8` и `8.8.4.4`
   (Параметры → Сеть и Интернет → изменить DNS-сервер).
2. Включите VPN.
3. Раздайте интернет с телефона и скачайте через него (тогда 126 МБ — это
   примерно 0,5 ГБ трафика с учётом скачивания).
4. Попросите знакомого скачать файл и передать вам через Telegram — файл
   `SideloadlySetup64.exe` можно просто переслать (126 МБ).

## ШАГ 1. Установить программы

По порядку: **iTunes → iCloud → Sideloadly**. После — перезагрузить компьютер.
(На Mac: только Sideloadly.)

---

## ШАГ 2. Подключить iPhone

1. Подключите iPhone кабелем к компьютеру.
2. Разблокируйте телефон.
3. На телефоне появится «Доверять этому компьютеру?» → **Доверять** → введите
   пароль экрана.

---

## ШАГ 3. Один раз синхронизировать телефон (убирает половину ошибок)

1. Откройте **iTunes** (на Mac — **Finder**).
2. Вверху слева нажмите на иконку телефона.
3. Нажмите **Синхронизировать**.
4. В iTunes: меню **Учётная запись → Авторизовать этот компьютер** → войдите
   своим **Apple ID** (обычный, бесплатный подойдёт).

---

## ШАГ 4. Подписать и установить

1. Запустите **Sideloadly**. Слева вверху должен появиться ваш iPhone.
   Если не появился — см. таблицу ошибок внизу.
2. В поле **Apple ID** введите свой Apple ID. Пароль пока не нужен.
3. **Перетащите** скачанный файл `.ipa` прямо в окно Sideloadly.
4. Галочку **Automatic App Refresh** оставьте **включённой** (она включена
   по умолчанию) — это автопродление подписи.
5. Нажмите **Start**.
6. Введите **пароль Apple ID**.
   Если включена двухфакторная аутентификация — Sideloadly попросит
   **6-значный код**, он придёт/покажется на iPhone. Пароль для приложений
   создавать не надо (с бесплатным Apple ID он не работает).
7. Дождитесь надписи **Done!** — обычно 10–60 секунд.

---

## ШАГ 5. Разрешить приложение на iPhone

1. **Настройки → Основные → VPN и управление устройством** →
   под «Профиль разработчика» нажмите на свой Apple ID → **Доверять**.
2. **Настройки → Конфиденциальность и безопасность → Режим разработчика** →
   включить → телефон перезагрузится, после перезагрузки подтвердите.
   Если пункта «Режим разработчика» не видно — запустите приложение и загляните
   в настройки снова, он появится.
3. Откройте приложение **«КубГАУ Студент»** и разрешите всё, что спросит:
   **Локальная сеть**, **Bluetooth**, уведомления.

---

## ШАГ 6. Настроить и отметиться

1. Вкладка **«Настройки»**:
   * «Сервер преподавателя» — адрес ноутбука, например `192.168.1.10`
     (порт 8000 подставится сам);
   * «Логин» — ваш логин со вкладки «Студенты» на компьютере преподавателя,
     «ФИО» — как в журнале;
   * нажмите **«Проверить связь»** — должно быть «есть».
2. Вкладка **«Отметиться»** → приложите iPhone к телефону преподавателя
   и подержите 1–2 секунды. Ждать галочку — «Вы отмечены».

---

## ЧЕРЕЗ 7 ДНЕЙ

Бесплатная подпись Apple живёт 7 дней. Чтобы не подписывать вручную:

1. Галочка **Automatic App Refresh** должна быть включена (шаг 4).
2. Включите Wi-Fi-синхронизацию: iTunes → устройство → **Обзор → Параметры →
   Синхронизировать с этим iPhone по Wi-Fi → Применить**
   (на Mac: Finder → «Показывать этот iPhone по Wi-Fi»).
3. Держите запущенным **Sideloadly Daemon** — иконка в трее рядом с часами.
4. Пока компьютер и телефон в одной Wi-Fi сети — подпись продлится сама.

Если компьютера рядом нет — раз в неделю подключите телефон кабелем и
повторите **ШАГ 4**. Данные приложения при этом сохраняются.

## ЧАСТЫЕ ОШИБКИ

| Что написано | Что делать |
|---|---|
| Sideloadly не видит iPhone | переустановите iTunes и iCloud по ссылкам из ШАГА 0, перезагрузите ПК, откройте iTunes и синхронизируйте; нажмите «Доверять» на телефоне; попробуйте другой кабель или USB-порт |
| `Login failed (-36607)` | в iTunes: **Учётная запись → Авторизовать этот компьютер** с тем же Apple ID, затем снова Start |
| `maximum App ID limit ... 10 App IDs every 7 days` | ограничение Apple на бесплатный аккаунт: подождите 4–7 дней или подпишите другим Apple ID |
| `maximum number of installed apps using a free developer profile` | на телефоне уже 3 приложения от бесплатного Apple ID — удалите лишние |
| `Untrusted Developer` | Настройки → Основные → VPN и управление устройством → Apple ID → Доверять |
| `Invalid argument ... .ipa` | антивирус удалил файл: скачайте IPA заново, добавьте папку в исключения |
| `NP_E_CONN_FAILED`, `AFC_E_MUX_ERROR` | стоят версии iTunes/iCloud из Microsoft Store: удалите, поставьте по ссылкам из ШАГА 0 |
| Приложение на экране не появилось | перезагрузите iPhone |
| Через 7 дней пишет «не удалось проверить разработчика» | истёк срок подписи: повторите ШАГ 4 |
| Ссылка на скачивание «не открывается» | скопируйте ссылку **целиком** без лишнего текста; если сайт всё равно не грузится — скачайте запасную программу Impactor с GitHub (см. ШАГ 0) или включите VPN |

## ЧАСТЫЕ ВОПРОСЫ

**Это точно бесплатно?**
Да. Платно только NFC-чтение на iPhone ($99/год у Apple) — но оно и не нужно:
отметка идёт по **Bluetooth**, он работает с бесплатным Apple ID.

**Можно поставить без компьютера?**
Нет: Apple разрешает подписывать приложения только с компьютера
(кабелем), поэтому нужен любой Windows-ноутбук или Mac.

**Каждый студент делает это сам?**
Да, каждый подписывает **своим** Apple ID на своём компьютере — 10 минут.
Раздать готовый файл «по ссылке» Apple не разрешает.

**Будет ли работать интернет у приложения?**
Интернет не нужен вообще. Телефон и ноутбук преподавателя просто должны быть
в одной Wi-Fi сети (подойдёт точка доступа с ноутбука).

# `ble_box` — считыватель по Bluetooth (без PN532)

В этой папке — всё, что нужно для отметок по **Bluetooth**: приложение студента, коробочка на
`ESP32` и программа ПК. Модуль `PN532` (NFC) здесь **не нужен вовсе**: коробочка теперь работает
по Bluetooth, и её видит любое приложение студента — и Android, и iPhone.

Что лежит в папке:

| Файл | Что это |
|---|---|
| [`esp32_ble_reader/esp32_ble_reader.ino`](esp32_ble_reader/esp32_ble_reader.ino) | Прошивка коробочки: `ESP32` + USB-кабель, ничего больше |
| `KubGAU-Student.apk` | Приложение студента **с Bluetooth** (версия 1.6) — скачивается из релиза: https://github.com/Igorr112323/visits11/releases/download/v1.0.0/KubGAU-Student.apk |
| `KubGAU-Journal.exe` | Программа ПК с поддержкой коробочки — **скачивается из релиза** (148 МБ, в репозиторий не кладём): https://github.com/Igorr112323/visits11/releases/download/v1.0.0/KubGAU-Journal.exe |

## 1. Как это работает (коротко)

```
телефон студента  --Bluetooth-->  телефон преподавателя  --USB-->  ПК (журнал)
       или
телефон студента  --Bluetooth-->  коробочка ESP32  --USB-->  ПК (журнал)
```

Отметку всегда подтверждает **программа на ПК** — она решает, идёт ли перекличка, тот ли это
студент и тот ли телефон. Телефон преподавателя для этого не обязателен: если подключена
коробочка, студенты отмечаются на ней, а преподаватель ведёт занятие в журнале.

Срабатывает только **вплотную** (0–2 см): пакет отправляется, когда уровень сигнала не слабее
порога `TOUCH_RSSI_THRESHOLD` в приложении студента (`android/student/.../BleMark.java`,
по умолчанию `-50` дБм; меньше — строже, например `-46`).

## 2. Коробочка на `ESP32` — что нужно

* `ESP32 Devkit V1` **или** `WEMOS D1 R32` (годится и прежняя плата — важно, чтобы она просто
  работала: PN532 больше не подключается).
* USB-кабель с передачей данных.
* Arduino IDE: плата `DOIT ESP32 DEVKIT V1` (или `ESP32 Dev Module`), скорость монитора `115200`.

Заливается файл `esp32_ble_reader/esp32_ble_reader.ino` — **без внешних библиотек**, всё
внутри ESP32 (Bluetooth идёт с ядра ESP32). Прошивка `v3` собирается и на старом ядре ESP32
(`2.x`), и на новом `3.x` (в `3.x` у характеристики другой тип получаемых данных — поэтому
данные берутся как двоичные, `getData()`/`getLength()`). Если в логе коробочки написано
`VISITS11-ESP32 v1` — в плату залит старый скетч (нужна `v3`).

### Мощность Bluetooth — настраивается сверху скетча

В самом начале файла:

```cpp
static const int BLE_TX_POWER_DBM = -12;
```

Допустимые значения: `-12`, `-9`, `-6`, `-3`, `0`, `3`, `6`, `9` (дБм). Чем меньше число, тем
«ближе» должен быть телефон. Меняете число → заливаете скетч заново.

Можно менять и **не перепрошиваясь** — строкой в мониторе порта (скорость `115200`):

| Команда | Что делает |
|---|---|
| `POWER:-6` | поставить мощность `-6` дБм (ответ `POWER:-6 OK`) |
| `POWER:9` | максимальная мощность |
| `POWER?` | показать текущую мощность |

Мощность **запоминается в плате**: после выключения и включения остаётся та, что была выставлена
последней. Число вверху скетча задаёт только первоначальное значение для новой платы.

Смена мощности сразу перезапускает рекламу — иначе новое значение применилось бы только со
следующего включения платы. Время от времени плата сама сообщает свою мощность программе ПК, и та
показывает её в поле.

### Мощность прямо из программы ПК

Вверху окна «Журнал КубГАУ» есть поле **«Мощность BLE … дБм»** (значение по умолчанию `-12`).
Впишите число (`-12`, `-9`, `-6`, `-3`, `0`, `3`, `6` или `9`) и нажмите **Enter** — программа
передаст `POWER:<число>` коробочке и покажет уведомление с применённым значением. Если кабель не
подключён или порт занят монитором Arduino IDE, придёт уведомление «коробочка не ответила».
Остальной интерфейс не переделан — добавлено только это поле.

### Корпус и коробка — что важно

Bluetooth (2,4 ГГц) **проходит сквозь пластик и бумагу**, поэтому напечатанный на 3D-принтере корпус
или пластиковая коробка сигнал не глушат: потеря 2–3 мм стенки — около 1–2 дБ, то есть незаметно.
Требования всего три:

* **никакого металла**: не годится филамент с металлом (металлик, глиттер, углеволокно), фольга,
  алюминиевый скотч, металлическая сетка. Металлические винты и закладные гайки (brass inserts)
  не должны быть рядом с антенной — антенна это край платы **с противоположной от USB стороны**;
* вокруг антенны оставьте **около 1 см** свободного места: не прижимайте её к толстой стенке и не
  заливайте компаундом;
* не ставьте коробку на металлическую поверхность (железный стол, поднос) — это расстраивает
  антенну сильнее, чем сам корпус.

Ради этого мощность поднимать не нужно.

### Что печатает коробочка

```
VISITS11-ESP32 v1
мощность Bluetooth: -12 дБм (меняется строкой вверху скетча или командой POWER:-6)
реклама запущена: ждём телефон студента
TAP:1:QVJISVBPVl9JSQ:a1b2c3d4e5f60718
REPLY:1:0:Иванов Иван
```

* `мощность Bluetooth: …` — какая мощность стоит сейчас (её же показывает поле в программе ПК);
* `TAP:…` — телефон студента приложен, коробочка спросила ПК;
* `REPLY:…` — ответ программы ПК (код `0` — отмечен, `2` — QR не найден, `4` — перекличка не идёт,
  `5` — телефон привязан к другому студенту);
* `TIMEOUT:…` — программа ПК не ответила за 6 секунд (не запущена или кабель не туда).

## 3. Приложение студента с Bluetooth

`KubGAU-Student.apk` — версия **1.6** (внутри `versionCode 7`). Ставится **поверх** прежней,
вход (считанный QR-код) сохраняется: приложение **никогда не сбрасывает вход само** — ни по
времени, ни после перезапуска, ни при ответе «кода нет в журнале». Сменить студента можно только
вручную — долгим нажатием на надпись на экране.

На экране отметки теперь две строки: сверху ФИО студента, после отметки — «Вы отмечены»,
снизу всегда «Просто поднесите телефон».

Что нужно на телефоне:

* включённый Bluetooth;
* разрешения: Android 12 и новее — «Рядом с устройством» (Bluetooth); Android 8–11 — «Геолокация»,
  и она должна быть включена в шторке (так устроен Android: без этого поиск Bluetooth-устройств
  не работает). Приложение спрашивает разрешение само при открытии экрана отметки;
* NFC остаётся как раньше — что первое окажется рядом (телефон преподавателя или коробочка),
  то и сработает.

Отметка выглядит так же: вибрация и надпись «Вы отмечены — ФИО».

## 4. Программа ПК

`KubGAU-Journal.exe` из релиза (ссылка выше) сам, без настроек, находит:

* телефон преподавателя по USB (как раньше), **и**
* коробочку `ESP32` по COM-порту (в списке команд `PING` → `VISITS11-ESP32`).

Оба источника идут в один и тот же учёт. Интерфейс не переделан: сверху добавлено только поле
мощности коробочки (Enter — применить), всё остальное как было.

Важно: пока открыт монитор порта в Arduino IDE, он держит COM-порт, и программа не сможет
работать с коробочкой — **закройте монитор** (или саму Arduino IDE), когда отмечаете студентов.

## 5. Проверка по шагам

1. Залить скетч, закрыть монитор порта (или оставить открытым только для проверки мощности).
2. Запустить `KubGAU-Journal.exe`, открыть занятие (перекличка идёт).
3. В приложении студента считать QR-код, приложить телефон к коробочке и подержать 1–2 секунды.
4. Ожидаемый лог коробочки: `TAP:1:…` → `REPLY:1:0:…`; в журнале студент отмечен, телефон
   вибрирует, на экране «Вы отмечены — ФИО».

Если отметка не проходит: в логе коробочки нет `TAP:` — телефон далеко или порог сигнала строгий
(поднимите мощность `POWER:0` или ослабьте порог в приложении студента); есть `TAP:`, но нет
`REPLY:` — программа ПК не запущена либо COM-порт занят монитором Arduino IDE.

## 6. Что не проверено

* Скетч **не компилировался** в этом репозитории (в сборочной среде нет Arduino IDE) — проверена
  только синтаксическая корректность. Если Arduino IDE покажет ошибку при загрузке — пришлите
  текст, поправим одной правкой.
* Приложение студента и программа ПК собираются автоматически (GitHub Actions) — их сборка
  проверена.

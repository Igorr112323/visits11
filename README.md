# КубГАУ · Учёт посещаемости (Visits11)

Полностью офлайн-система учёта посещаемости: преподаватель отмечает студентов
касанием телефон-к-телефону (NFC), журнал ведётся на ПК. Интернета не нужно
вообще, Wi-Fi не используется: телефон преподавателя связан с ПК USB-кабелем.

**Логинов и паролей в системе нет.** Вход студента — по его личному QR-коду:
навести камеру или выбрать сохранённую картинку из галереи.

| Файл | Что это | Где видно название |
|---|---|---|
| `KubGAU-Journal.exe` | Программа на ПК (Журнал КубГАУ) | окно «Журнал КубГАУ» |
| `KubGAU-Teacher.apk` | Телефон преподавателя | приложение «КубГАУ Преподаватель» |
| `KubGAU-Student.apk` | Телефон студента (Android) | приложение «КубГАУ Студент» |
| `Visits11-Student-iOS-unsigned.ipa` | Телефон студента (iPhone) | — |

Все файлы — в [релизах](https://github.com/Igorr112323/visits11/releases)
(страница **КубГАУ · Учёт посещаемости**). Имена файлов — латиницей:
GitHub не допускает кириллицу в именах файлов, все названия внутри — русские.

## Быстрый старт

**ПК (преподаватель):**
1. Скачайте `KubGAU-Journal.exe` в любую папку и запустите (Windows 10/11 x64,
   установка не требуется).
2. Вкладка «Студенты» → создайте группу → добавьте студентов (или импортируйте
   из Word). Каждому автоматически выдаётся личный QR-код.
3. Вкладка «Занятия» → выберите группу → **«Начать перекличку»**.
   Пока перекличка идёт — студенты отмечаются.

**Телефон преподавателя:**
1. Установите `KubGAU-Teacher.apk`.
2. Подключите телефон к ПК USB-кабелем.
3. Приложение само попросит включить «USB-модем» и откроет нужный экран
   настроек (единственный тумблер, который Android не разрешает включать
   приложениям). Включите его.
4. Дождитесь зелёной надписи **«ПК подключён, NFC готов»** — телефон-терминал
   готов, больше ничего вводить не нужно. Положите телефон на стол.

**Телефон студента (Android):**
1. Установите `KubGAU-Student.apk`.
2. Первый запуск: **«Сканировать QR-код»** (наведите камеру на свой код) или
   **«Загрузить из галереи»** (выберите сохранённую картинку с кодом) —
   один раз и навсегда.
3. Чтобы отметиться: откройте приложение и приложите телефон **задней стороной**
   к телефону преподавателя. Успех — двойная вибрация и «Вы отмечены».

**iPhone:** то же самое (вход — по QR камерой или из галереи), но приложение
нужно подписать своим Apple ID через [Sideloadly](https://sideloadly.io/)
(бесплатно, подпись живёт 7 дней) — см. раздел [iOS](#ios-iphone). Apple не
позволяет устанавливать сторонние приложения без аккаунта разработчика ($99/год).

## Как это работает

```
   ┌──────────┐   USB-кабель («USB-модем»)      ┌──────────────────┐
   │   ПК     │  ←───────────────────────────→  │ Телефон           │
   │ Журнал   │   все соединения исходящие      │ преподавателя     │
   │ КубГАУ   │   со стороны ПК                 │ (NFC-терминал)    │
   └──────────┘                                 └──────────────────┘
                                                     ↑  NFC-касание
   ┌─────────────────────────────────────────────────┴────────────┐
   │  Телефоны студентов (Android и iPhone, считыватели)          │
   └──────────────────────────────────────────────────────────────┘
```

- **NFC «телефон к телефону».** Телефон преподавателя «притворяется картой»
  (Android Host Card Emulation), телефон студента работает считывателем.
  Отметиться может только тот, кто физически приложил телефон, — переслать
  скриншот или отметить «за соседа» невозможно.
- **Только кабель, без сети.** ПК сам забирает касания с телефона преподавателя
  (`GET /event`, long-poll) и возвращает ответ (`POST /event_result`). Телефон
  преподавателя слушает **только адрес USB-интерфейса** — из Wi-Fi он недоступен
  вообще. Настраивать брандмауэр Windows не нужно: включён он или выключен —
  без разницы. (Разрешение «Интернет» в приложении преподавателя объявлено
  вынужденно: без него Android запрещает создавать даже свой сокет. Наружу
  приложение не обращается никуда.)
- **У приложений студентов нет доступа в сеть.** У Android-приложения нет даже
  разрешения `INTERNET`; на iPhone — никаких сетевых запросов. Студенческий
  телефон общается с миром одним способом: NFC-касание и QR-код.
- **Wi-Fi-фолбэк убран.** Раньше телефоны без NFC могли отметиться через
  Wi-Fi+QR — теперь такого пути нет: отметка ставится только касанием,
  иначе — вручную преподавателем в журнале.

## Вход студента по QR-коду (без сервера и без сети)

У каждого студента есть личный **постоянный** QR-код — картинка PNG, в которой
лежит только его код (128 бит случайности). Преподаватель выгружает все коды
одной папкой или показывает код на экране, студент входит одним движением:

```
ПК «Журнал КубГАУ»                                 Студент
Студенты → «Экспорт QR-кодов»   ──────┐        «Сканировать QR-код»
   папка «QR-коды ИСП-31»             │        (камера на код с экрана ПК)
   ФИО.png + «Как войти.txt»          └──────→ или «Загрузить из галереи»
                                                (сохранённая картинка)
                                                      │
                                                код сохраняется в телефоне
                                                      │
                                                дальше — NFC-касание
```

- Кнопка **«QR-код»** напротив каждого студента в таблице: окно с картинкой —
  можно навести камеру прямо на экран или нажать «Сохранить картинку» и отправить
  студенту.
- Вход работает полностью без сети: в QR нет ничего, кроме кода студента.
- Второй экземпляр картинки бесполезен: аккаунт привязывается к первому телефону,
  и отметка с чужого устройства отклоняется (см. «Защита от накруток»).
- QR-код постоянный: выдали один раз — студент входит им весь семестр.
  Перевыпуск — удалить студента и создать заново (код сменится).

## Возможности

### Программа на ПК («Журнал КубГАУ»)
- **Занятия** — выбор группы, «Начать перекличку», живой список с «Есть»/«Нет»,
  круговая статистика; клик по строке — ручная отметка/снятие.
- **Студенты** — группы и студенты: создание, **удаление** (✕ у студента,
  «Удалить группу» — с подтверждением), **«QR-код»** напротив каждого студента
  (показать и сохранить картинку), **«Экспорт QR-кодов»** — папка
  «QR-коды &lt;группа&gt;» с картинкой на каждого и инструкцией «Как войти.txt»,
  импорт списка из Word (.docx), статус «привязан / не привязан» по телефону.
- **Журнал** — история занятий, детали посещаемости, экспорт занятия в Word.
- **Подсказки преподавателю**: каждое неудачное касание видно на ПК —
  «кода нет в журнале», «перекличка не идёт» и т.п.
- Светлая и тёмная темы (сохраняются в `settings.json` рядом с exe).

### Защита от накруток
- **Привязка аккаунта к устройству.** Первое касание привязывает студента
  к его телефону (Android — `ANDROID_ID`, iPhone — UUID). Отметка с чужого
  телефона отклоняется (студент видит «Этот телефон привязан к другому студенту»).
- **«Что-то не так».** Если телефон, уже привязанный к одному студенту, попытались
  использовать для отметки другого — попытка блокируется, а строка настоящего
  владельца телефона подсвечивается меткой «⚠ Что-то не так».
- **Перепутать ответы нельзя.** Каждый ответ касания снабжён номером запроса:
  ответ одного студента физически не может достаться другому.
- **Вибрация.** При успешной отметке оба телефона делают заметный двойной пульс.

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| Телефон препода: «Нет связи с ПК — нажмите, чтобы включить USB-модем» | «USB-модем» выключен либо кабель не подключён. Нажмите на надпись — откроется нужный экран настроек. |
| Телефон препода: «USB-модем включён (192.168.42.129). Запустите «Журнал КубГАУ» на ПК» | Кабель и модем работают, но на ПК не запущена программа «Журнал КубГАУ» (или она уже открыта — тогда подождите пару секунд). |
| Телефон препода: «NFC ВЫКЛЮЧЕН» | Нажмите на надпись → включите NFC в настройках. |
| Студент: «Такого QR-кода нет в журнале» | Кода нет в базе: студента удалили или код из другой школы/файла. Возьмите новый QR-код у преподавателя. |
| Студент: «Этот телефон привязан к другому студенту» | Аккаунт привязан к прежнему телефону. Привязку снимают, удалив студента и создав его заново (код при этом сменится). |
| Студент: «В этой картинке нет кода для входа» | Выбрана не та картинка или снимок пересжат/обрезан. Нужен файл PNG из папки «QR-коды …» целиком. |
| Студент: камера не открывается | Разрешите приложению доступ к камере (Android спросит при первом нажатии «Сканировать QR-код»; iPhone — в Настройках → Visits11Student). Запасной путь — «Загрузить из галереи». |
| Студент: хочу ввести другого студента | Долгое нажатие по надписи «Приложите телефон…» — вернёт экран входа. |
| Студент: QR не сохраняется в галерею | Картинку из мессенджера нужно именно скачать/сохранить, а не открыть во встроенном просмотрщике. |
| Вибрации нет | Проверьте, что вибрация включена в настройках телефона (на части Xiaomi/Huawei слабая по умолчанию). |
| На ПК пропали студенты и группы | exe запущен из другой папки: база `attendance.db` лежит рядом с exe. Запустите из прежней папки (или перенесите файл базы). |

## Протокол обмена (для разработчиков)

### NFC (телефон студента → телефон преподавателя)
Выбор приложения: `00 A4 04 00 07 F0391101020304` → `9000`.
Команда (INS `0x10`): данные студента в UTF-8 — `код-из-QR-кода\nid-устройства` + `9000`.

Коды ответа (первый байт), дальше значение:
`0` — отмечен (дальше имя студента) · `2` — такого QR-кода нет в журнале ·
`4` — не получилось (перекличка не идёт / ПК недоступен) ·
`5` — телефон привязан к другому студенту.

Телефон преподавателя кладёт запрос в очередь; ПК забирает его по
`GET /event?wait=3000` (200 + JSON или 204), обрабатывает и возвращает ответ
в `POST /event_result` (`{"id":N,"code":C,"value":"..."}` — `id` защищает от
перепутанных ответов). Обмен касаниями сериализован, ожидание ответа ≤ 4 с
(укладывается в 5-секундный таймаут IsoDep).

### Телефон преподавателя (порт 8090, только USB-интерфейс)
- `GET /info` → `{"app":"visits11-teacher"}` — по этому ответу ПК находит телефон;
- `GET /event?wait=3000` → JSON с очередным касанием либо `204`;
- `POST /event_result` ← JSON-ответ ПК на касание.

Из Wi-Fi телефон недоступен: сервер слушает исключительно адрес USB-интерфейса
(`usb0`/`rndis0`), а пока кабель не подключён — не слушает ничего.

### QR-код входа студента (только ASCII)

1-я строка — машинная, её читают приложения студента; 2-я и 3-я — для человека:

```
V11S2.<код-b64url>.<ФИО-b64url>.<crc32>
Student: Ivanov Ivan Ivanovich
Code: QVJISVBPVl9JSQ
```

- `V11S2` — версия формата; поля в base64url без выравнивания (поэтому кириллица
  в ФИО не ломает кодировку — QR остаётся ASCII-текстом).
- `crc32` — 8 hex-символов (IEEE 802.3, одинаково считается на ПК, Android и
  iPhone): отсекает чужие картинки и кривые распознавания. Это контроль целостности,
  не подпись.
- Формат собирается в `Services/StudentQr.cs`; при экспорте ПК проверяет
  собственный код разбором (CRC) — картинки не разойдутся с тем, что читают приложения.

### База данных (SQLite, `attendance.db` рядом с exe)
Таблицы: `Groups`, `Students` (`FullName`, `QrToken` — код из QR, `DeviceId` —
привязка телефона), `Lessons`, `Attendance`. Логинов и паролей нет;
таблица сессий не нужна — вход выполняет QR-код.

## Сборка из исходников

Полные команды, требования и решение типичных проблем — в **[BUILD.md](BUILD.md)**.
Коротко:

**ПК (Windows, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)):**
```bash
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true -p:SelfContained=true -p:IncludeNativeLibrariesForSelfExtract=true
```

**Android (JDK 17, Gradle 8.9, SDK 34)** — два модуля, `app` и `student`, без flavor'ов:
```bash
cd android && gradle assembleRelease
# app/build/outputs/apk/release/app-release.apk       — преподаватель
# student/build/outputs/apk/release/student-release.apk — студент
```

**iOS:** SwiftUI + CoreNFC + Vision, проект генерируется из `ios/project.yml`.

### Автосборка (GitHub Actions)
- `build.yml` → `KubGAU-Journal.exe` (Windows-раннер, single-file, релиз)
- `apk.yml` → `KubGAU-Teacher.apk`, `KubGAU-Student.apk` (релиз)
- `ios.yml` → `Visits11-Student-iOS-unsigned.ipa` (macOS-раннер, релиз)

Раннер возвращает в релиз только актуальные имена файлов (старые удаляет).

## iOS (iPhone)
HCE на iPhone невозможна — телефон студента работает считывателем (как и на
Android). Распознавание QR-кода сделано системными средствами: `Vision`
(картинки) и `AVFoundation` (камера), выбор фото — `PHPicker`. Разрешение нужно
только на камеру (`NSCameraUsageDescription`); доступ к галерее не запрашивается.
Apple не даёт ставить сторонние приложения без аккаунта разработчика ($99/год),
поэтому ipa не подписан: для теста подпишите своим Apple ID через Sideloadly
(подпись живёт 7 дней).

# КубГАУ · Учёт посещаемости (Visits11)

Полностью офлайн-система учёта посещаемости на Bluetooth BLE. Преподаватель
ведёт журнал на ПК (Windows), студенты отмеча­ются, поднеся свой телефон к
терминалу. **Интернет не нужен вообще:** ни на ПК, ни на телефонах, ни на плате.
**Логинов и паролей нет:** студент входит по своему личному QR-коду один раз —
камерой телефона или картинкой из галереи.

## Два варианта терминала

Система укладывается в **одну папку с двумя вариантами** — выберите свой:

| | **Вариант 1: телефон преподавателя** | **Вариант 2: плата ESP32** |
|---|---|---|
| Терминал | Android-телефон преподавателя по USB-кабелю («USB-модем») | Плата ESP32 Devkit V1 / ESP32-WROOM-32 по USB |
| Программа на ПК | `KubGAU-Journal-Phone.exe` | `KubGAU-Journal.exe` |
| Нужное ПО для установки | `KubGAU-Teacher.apk` + EXE | Прошивка платы (один раз) + EXE |
| Дальность отметки | Задается уровнем Bluetooth в EXE | Задается уровнем Bluetooth в EXE: Минимум = вплотную … Высокая ≈ 50–70 см |
| Проверка расстояния | Фильтр в приложении преподавателя | **Сама плата** измеряет сигнал телефона перед каждой отметкой |
| Инструкция | [packages/Phone/README.md](packages/Phone/README.md) | [packages/ESP32/README.md](packages/ESP32/README.md) |

Оба варианта дают один и тот же журнал, одну и ту же базу, те же QR-коды и
**одинаковые приложения студентов** — телефон студента одинаково работает и с
телефоном преподавателя, и с платой. Переключаться между вариантами можно в
любой момент.

## Быстрый старт

**1. ПК (преподаватель).** Распакуйте нужный вариант из
`KubGAU-BLE-two-folders.zip` в любую папку и запустите EXE (Windows 10/11 x64,
установка не нужна). База создаётся сама (`%LOCALAPPDATA%\Visits11\ESP32` или
`...\Phone`); если запустить EXE из папки старого журнала — старая база
импортируется автоматически. Вкладка «Студенты» → группа → студенты (можно
импортировать из Word). Каждому студенту — личный QR-код (кнопка «QR-код» или
«Экспорт QR-кодов» — папка с картинками).

**2. Терминал.**
- *Вариант 1:* установите `KubGAU-Teacher.apk`, подключите телефон к ПК
  USB-кабелем, включите «USB-модем» — приложение откроет нужный экран настроек
  само. Дождитесь «ПК подключён, BLE готов» и положите телефон на стол.
- *Вариант 2:* один раз прошейте плату `Visits11Ble.ino` (Arduino IDE →
  esp32 by Espressif → DOIT ESP32 DEVKIT V1 → «Загрузить»), подключите плату
  USB-кабелем **с передачей данных**. EXE найдёт её сам — выбирать COM-порт не
  нужно. Кружок вверху окна: зелёный = плата подключена.

**3. Телефон студента.** Установите `KubGAU-Student.apk` (или подпишите IPA для
iPhone), один раз войдите по своему QR-коду («Сканировать QR-код» или
«Загрузить из галереи») и включите Bluetooth. На Android 8–11 нужен также
включённый GPS — это требование системы к BLE-поиску, не доступ приложения к
сети.

**4. Перекличка.** В журнале: «Занятия» → группа → **«Начать перекличку»**.
Студент открывает приложение и подносит телефон к терминалу. Успех — надпись
«Вы отмечены» на 5 секунд и вибрация ровно в момент записи; дальше телефон сам
готов к следующей отметке.

## Как это работает

```
   Вариант 2 (плата):                    Вариант 1 (телефон преподавателя):

   ┌─────────┐  USB (данные)  ┌──────────────────────┐
   │   ПК    │ ←────────────→ │  плата ESP32         │
   │  Журнал │   EXE сам      │  (BLE-терминал)      │
   └─────────┘   подключается └──────────┬───────────┘
                                          ↑ BLE-сигнал
   ┌───────────────────────────────────────────────┐
   │  Телефоны студентов (Android / iPhone)         │
   └───────────────────────────────────────────────┘
```

- **Уровень Bluetooth в EXE задаёт расстояние отметки**: Минимум = приложить
  вплотную, Низкая ≈ 15–20 см, Средняя ≈ 30–40 см, Высокая ≈ 50–70 см (точно —
  зависит от телефона и обстановки). Смена уровня действует сразу.
- **В варианте с платой расстояние проверяет сама плата**, а не приложение:
  перед каждой отметкой она трижды измеряет сигнал подключившегося телефона и
  отказывает, если тот слабее порога уровня. Плата сообщает телефону свой
  порог, поэтому телефон подключается ровно там, где отметка возможна — без
  лишних «слишком далеко».
- **Вариант с телефоном преподавателя** — тот же BLE-протокол, проверка
  близости выполняется в приложении преподавателя.
- **Только кабель, без сети.** В варианте 1 ПК общается с телефоном через
  USB-интерфейс (телефон слушает только его — из Wi-Fi недоступен). В варианте
  2 связь чисто USB-сериальная. Студенческие приложения не имеют доступа в сеть.

## Вход студента по QR-коду (без сервера и без сети)

Личный QR-код — картинка PNG, в которой лежит только код студента (128 бит
случайности). Выдаётся один раз, действует весь семестр. В QR нет ничего,
кроме кода: вход работает полностью офлайн.

- Аккаунт **привязывается к первому телефону**: отметка с чужого устройства
  отклоняется («Этот телефон привязан к другому студенту»).
- Если телефоном, уже привязанным к одному студенту, пытаются отметиться
  другого — попытка блокируется, а настоящий владелец подсвечивается меткой
  «⚠ Что-то не так».
- Ответы защищены номерами запросов: отметка одного студента физически не
  может достаться другому.

## Защита и её пределы (честно)

- Отметиться может только тот, чей телефон физически в зоне терминала
  (проверка сигнала на стороне терминала).
- BLE-сигнал — эвристика близости, **не криптографическое** доказательство
  присутствия: защита от ретранслятора/усилителя она не даёт. **Высокий уровень
  (свыше «Средней») — ослабленная защита от коридора:** перед использованием
  проверьте, что через дверь/коридор отметка не проходит.
- Старый NFC-релиз v1.0.0 не изменён и остаётся доступен в релизах.

## Решение проблем (коротко)

| Симптом | Решение |
|---|---|
| Плата не определяется (красный кружок) | Кабель с передачей данных, драйвер CP210x/CH340, закрыть монитор порта Arduino IDE, питание платы |
| Телефон студента не находит терминал | Включите Bluetooth; Android 8–11 — также GPS; поднесите ближе |
| «Поднесите телефон ближе к терминалу» | Сигнал слабее порога уровня — поднесите ближе или повысьте уровень в EXE |
| «Этот телефон привязан к другому студенту» | Привязка к прежнему телефону: в журнале «Сбросить» у студента |
| iPhone: не устанавливается IPA | Нужно подписать: Sideloadly, свой Apple ID (бесплатно, ~7 дней) |
| Пропало содержимое журнала | EXE запущен не из той папки (вариант 1 со старой базы) либо сменён пользователь Windows: база хранится в папке пользователя |

Подробные инструкции — в [packages/Phone/README.md](packages/Phone/README.md)
и [packages/ESP32/README.md](packages/ESP32/README.md) (они же лежат внутри
каждой папки в ZIP-комплектах).


## Сборка и автосборка

Ручная сборка (команды и требования) — в [BUILD.md](BUILD.md).
Автосборка — GitHub Actions, workflow **BLE distribution**
(`.github/workflows/ble.yml`): каждый коммит в ветку собирает Windows-EXE
(оба режима), оба APK, IPA, прошивку ESP32 и контрактные тесты, и публикует
релиз со всеми файлами.

# Комплект «Телефон преподавателя» — Bluetooth BLE

Этот способ сохранён: ПК + телефон преподавателя по USB-модему. NFC не нужен ни на одном телефоне.

1. Сохраните резервную копию старой `attendance.db`, закройте старый журнал и перенесите базу рядом с новым EXE. Не запускайте одновременно два журнала.
2. Установите `KubGAU-Teacher.apk`, разрешите Bluetooth и включите его.
3. Подключите телефон преподавателя USB-кабелем к ПК, включите «USB-модем», запустите EXE. Подключение определяется автоматически.
4. Студентам установите APK или подписанный IPA (iPhone требует подписи, например через Sideloadly). Приложения студента здесь и в комплекте ESP32 — **одни и те же файлы**.
5. Начните перекличку. Студент входит по QR один раз, открывает приложение и подносит телефон к терминалу преподавателя.
6. Поле Bluetooth вверху EXE задаёт мощность рекламы BLE: минимум, низкая, средняя, высокая. Реальные dBm зависят от телефона. Дальность не гарантируется в сантиметрах.

Не копируйте `board.mode` из комплекта ESP32 в эту папку: это переключатель транспорта журнала.

Вход сохраняется после закрытия приложения, потери связи и отключения Bluetooth. Выход только долгим нажатием на надпись или по ответу журнала «такого QR нет». Чужая привязка — сообщение об ошибке, не выход.

Старые APK подписывались временным ключом CI; обновление поверх них может не установиться из-за отличающейся подписи. Не удаляйте старое приложение без сохранённого QR. В прежнем Android вместо уникального ID отправлялось `android_id`; при ошибке привязки нажмите «Сбросить» у нужного студента в журнале.

На Android 8–11 BLE-поиск требует геолокацию. iPhone IPA необходимо подписать; бесплатную подпись обычно обновляют каждые 7 дней. Подробности и ограничения — также в инструкции комплекта ESP32.

## Освобождение терминала после отметки
После успешного ответа журнала приложение сразу закрывает BLE-соединение и больше не подключается в текущем открытии экрана. Аккаунт остаётся сохранённым. Для следующей отметки сверните и снова откройте приложение.
